# HavaMana Climate Digital Twin

React and Vite frontend for the AI-powered climate digital twin project.

The first pilot region is Karnataka, with Bengaluru as the primary dashboard location. The interface is designed for government planners, agriculture groups, climate researchers, and the public.

## Run locally

```bash
npm install
npm run dev
```

Other commands:

```bash
npm run build
npm run lint
```

The current dashboard uses mock data while the Flask API and model services are being developed.
